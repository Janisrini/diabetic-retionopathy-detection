# diabetic-retionopathy-detection
A deep learning–based mini project that classifies retinal fundus images as Normal or Diabetic Retinopathy. The system uses a CNN model to analyze eye images and provides near real-time predictions to support early screening and awareness.
## Problem Statement
Early detection of diabetic retinopathy using eye images.

## Technologies Used
- Python
- CNN
- TensorFlow / Keras

## Dataset
- Kaggle Diabetic Retinopathy Dataset

## How to Run
1. Install requirements
2. Run train.py
3. prediction.py

## Future Scope
- Real-time camera detection
- Multi-stage DR classification
